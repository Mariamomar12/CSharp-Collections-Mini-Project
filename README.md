# C# Collections and Advanced Concepts Mini-Project

A C# console application developed to practice programming concepts through student data management and grade-based operations.

## Features

* Add and remove student records.
* Display student information.
* Filter students based on their grades.
* Trigger event-based notifications when a student's grade reaches 95 or above.
* Apply basic input and data validation.

## Concepts Demonstrated

* Object-Oriented Programming (OOP)
* Collections using `List<T>`
* Generics
* Events and Event Handling
* Grade-Based Filtering
* Basic Data Validation
* Delegates

## Technologies

* C#

## Getting Started

1. Clone or download this repository.
2. Open the solution file in Visual Studio, if included.
3. Build and run the project.
